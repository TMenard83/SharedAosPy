# tournament_kit — modes de roster

Lire avant de toucher `modes.py`, `split_pool.py` ou un comportement propre à un mode ; vue d'ensemble dans [`README.md`](README.md).

### Roster modes (`build_roster_pdf(..., mode=...)` / `aospy roster pdf --mode ...`)

Everything described above is the `hybrid` mode (default, unchanged historical behavior). 4 more variants exist, selected by one `mode` argument threaded through `resolve_rules`/`build_roster_pdf` (`RosterMode`, defined in `resolution/rules_resolution.py` and re-exported by `pdf_builder.py`) and gating every per-category resolution the same way:

- **`en`**: Wahapedia only — the French battletome-page-copy fallback tier (`_STATIC_RULE_SECTIONS`, and the French-page tiers of the spell-lore/manifestation-lore chains) is simply skipped (`resolve_rules`'s `allow_page_copy = mode == "hybrid"`); anything Wahapedia doesn't cover shows up as a plain `RosterPdfResult.rules_unmatched`/`units_unmatched` entry, never an interactive prompt — the CLI run itself never blocks waiting on input. (A separate, conversational workflow — comparing Wahapedia's English data against an actual battletome/faction-pack scan and asking for a missing page when a real gap turns up — is a curation/audit concern, not something this mode's plumbing does; out of scope for `pdf_builder.py` itself.)
- **`fr`**: like `en` (no page copy) but every Wahapedia-resolved category also passes through `data/json/faction_rules_fr.json` (`sources/faction_rules_fr.py`, see below) via `rules_resolution._fr_patch`, which corrects/completes the pool wherever a curated French entry exists for that faction/category/unit — a faction with nothing curated yet degrades naturally to the same result as `en`, no special-casing needed.
- **`fr-extended`**: `fr` plus one more rule card, "Aptitudes Génériques — MdG26-27" (`data/json/generic_core_abilities.json` / `tournament_kit/sources/generic_core_abilities.py`, a loader twin of `season_rules.py` for the *complete* `MdG26-27 Aptitudes.pdf` rather than just its page-5 season rules) — omitted entirely (not an empty card) if that file has no entry.
- **`fr-split`**: same *content* as `fr-extended` (`ModeSpec.french` in `modes.py` gates every French-patch check, so a new French mode only needs a `MODES` entry there), different *layout*: every warscroll's abilities leave its unit card (which keeps only stat bar + weapons + keywords) and join the merged rule pool, each tagged via `AbilityEntry.warscrolls` (rendered as a dedicated night-blue pill, `render/pills._warscroll_pills`; an identical ability carried by several units is merged into one entry with one pill per unit, `split_pool._warscroll_ability_pool`). That pool is then split into three rule cards, each starting on its own page: "Déploiement" (every `deploy`-band ability, which precedes any turn, followed by the green "N'importe quelle phase" band, which would otherwise be duplicated on both turn cards), "Mon tour" / "Tour adverse" (by `render/phases.ability_turn_sides` — the same `Your`/`Enemy`/`Any` qualifier regex as the "Ma phase"/"Phase ennemi"/"Les 2 phases" pills; passives, reactions, "Début de round" and unqualified conditions go on *both*). Cards order their bands by `render/phases.SPLIT_PHASE_ORDER` (green band right after deployment, `render_rule_card(..., phase_order=...)`; other modes and unit cards keep `_PHASE_ORDER`), so "Fin de tour" is a turn card's last band; the battle tactic cards are not a separate section in this mode, they follow right after it, inside "Mon tour"'s page flow. "Tour adverse" drops « En Avant, vers la Victoire » (charge reroll command) unless another ability on that card carries the `Charge` keyword (`split_pool._drop_enemy_charge_reroll`) — otherwise the only unit charging there is the Contre-Charge one, which already used its one command. « Au Pas de Course » / « At the Double » (reaction to a Run, only possible in your own movement phase) is always dropped from « Tour adverse » (`split_pool._MINE_ONLY_KEYS`). A reaction limited to « in your … phase » / « dans votre phase » goes on « Mon tour » only (`render/phases._IN_YOUR_PHASE_RE`, e.g. « Avancer dans la Trace »). Turn cards also hide the "Ma phase"/"Phase ennemi" pills (`render_rule_card(..., hide_turn_qualifier=True)`, the card title already says it; "Les 2 phases" stays). Passive abilities that change the unit's own profile with its damage taken (`render/phases.is_profile_modifier`, e.g. "Battle Damaged"/"Stigmates de Guerre", bilingual regex) stay on the warscroll card instead of joining the turn cards. **Choice sub-sections** (`split_pool._CHOICE_CLUSTERS`, one `_ChoiceCluster` per faction, applied by `_apply_choice_clusters`): a titled sub-section opening a phase band with the ability that makes you *choose* followed by every option — FEC "Délires" ("Royaume Délirant" + every `Delusion`-keyword ability, `fr-extended`+`fr-split`), BoK "Dîme de Sang" ("Des Crânes pour le Trône de Crânes", "Trempés de Sang", then every `Blood Tithe` ability by cost, `fr-extended`+`fr-split`, both turn cards), DoK "Bénédictions de Khaine" ("Rites de Sang" then "Bénédictions de Khaine", in the *Fin de tour* band, `fr-extended`+`fr-split`). Any reaction to a choice ability (Wahapedia condition « You declared the ‘<name>’ ability », `_is_choice_reaction`, e.g. Blood Hags' "Offrandes Pourpres") is moved into its sub-section. In `fr-extended` only faction rules are pooled, so warscroll options/reactions stay on their unit card there. An option acting in another phase is deliberately *also* kept there (duplicate); one already in the cluster's phase is moved rather than duplicated. `classify_phase` trusts a cluster copy's `ability_phase` over the phase its `condition` names. A sectioned phase band that misses the space left on its page by 5% or less is laid out again wider then scaled down to the card width to fit there (`render/layout._SHRINK_TO_FIT`, `_SectionedPhaseGroup.rebuild`, `_ShrunkFlowable` — same width as the other bands, text slightly smaller) rather than moved to the next page. A choice sub-section must fit on one page (user request): `render/layout._choice_segments` makes it its own chunk with a taller budget (`_MAX_CHOICE_HEIGHT`, 265mm vs. `_MAX_GROUP_HEIGHT`'s 240mm — the real frame is ~273mm), and its defining keyword pill (`DELUSION`/`BLOOD TITHE`) is hidden inside it, while a warscroll option keeps its unit pill there (the sub-section title doesn't name the unit, `_warscroll_pills`); 3 columns were tried and came out taller. **Rule**: each cost type has its own `_CastBadge` silhouette (`_CAST_BADGE_SHAPES` — circle spell, diamond prayer, hexagon CP, blood drop blood tithe), never shared (`test_cast_badge_shapes_are_unique`). These cards' phase bands are far bigger than any other mode's, which is why `_chunk_group` measures at the real column count and splits an oversized category cluster per ability.

- **Source badge** (every mode): each ability shows exactly one text-source pill (`render/pills._TEXT_SOURCE_KEYWORDS`: BT, BT (trad.), FP, Aqshy, MdG, Simple, Wahapedia — the last one is the fallback when nothing else applies); SIMPLE replaces the others. SAISON/BASE are properties, not sources (season rules carry both SAISON and MdG). All source pills share one color (`render/theme._BADGE_SOURCE`, anthracite grey); so do the « sub-source » origin pills Traits de Bataille/Formation (`_SUB_SOURCE_PREFIXES`); the `Mouvement`/`Move` keyword pill uses the movement-phase grey (`_PHASE_COLORS["move"]`).
- **Tactic card special rules** (every mode): `split_pool._tactic_special_rules` adds each cited card's `special_rule` (e.g. Blazing Onslaught's lair) to the Deployment band, since it is played before the first turn while the card itself is only read at end of turn.
- **Deployment band order** (`fr-extended`/`fr-split`/`fr-split-simple`): `split_pool._DEPLOY_ORDER` (game-sequence order: Placez le Champ de Bataille, Terrain de Faction, Régiment, Unité, Souffler sur les Braises) opens the band — it also lists « Début de Round de Bataille » (rules 12.0 steps 1-2, same numbered-steps model), which opens the « Début de Round » band of both turn cards, one ability per row (`AbilityEntry.full_width` — span 3 in the sectioned grid, single column for that phase in `render_rule_card`).
- **`fr-split-simple`**: guiding principles in `data/roster_simplifications.md` (read it first). `fr-split` (`ModeSpec.split`) + **per-list simplifications dictated and validated one by one by the user** — never propose-and-apply on my own. `data/json/roster_simplifications.json` (`sources/roster_simplifications.py`), `all_lists` section (applies to every list in this mode, e.g. `add_keywords`, `compress_spell_declare` — a 2D6 spell/summon's « Annonce » reduced to « Cible : … », `compress_declare` — any other ability's « Annonce : Choisissez comme cible(s) X » becomes « Cible(s) : X » (SIMPLE badge), `compress_prayer_declare` — same for a prayer (« Choisissez un Prêtre … ami pour réciter cette prière » + D6 roll dropped; a named priest, e.g. a Regiment of Renown's, is kept), `merge_into` — an ability folded into another, e.g. « Musicien » into « Ralliement », only when the folded one is in the pool, applied to the final split pool by `RosterSimplifications.merge`) plus `lists` keyed by list file stem. **Everything there is `fr-split-simple`-only** — never touch shared files (`generic_core_abilities.json`, `faction_rules_fr.json`) for a simplification, so `fr-split`/`fr-extended` stay unaffected. Exception validated by the user: a SIMPLE badge on a generic rule whose shared text is *already* a compression (« Placez le Champ de Bataille ») lives in `generic_core_abilities.json`'s `keywords`, so it shows in `fr-extended`/`fr-split` too (grey source pill like every other source badge, `render/theme._BADGE_SOURCE`). Per-list keys: `units.<unit>.add_abilities` (synthesis abilities, optional `note` rendered small/grey as provenance), `keep_on_warscroll` (ability names, EN+FR, that stay on their warscroll card instead of joining the turn cards), `description_overrides` (ability name -> replacement text, e.g. reordered/trimmed runes), `warscroll_order` (cards put first, in that order — cards go 2 per row, so this pairs cards of similar height), `units.<unit>.description_overrides` (text override scoped to that unit's abilities, e.g. the Daemon Prince's copy of « Voué à Nurgle » reduced to *Appliqué* while the army trait keeps its text), `units.<unit>.stats` (displayed `move`/`save`/`control`/`health`/`ward`/`points` replaced), `option_labels` (cover-page relabel of a ` • option`, e.g. the chosen rune; enhancement resolution still reads the original), `unit_aliases` (display name -> `{unit, options}`: the list entry with that name and those options becomes a separately-named Hero — own card titled with the alias, warscroll name as subtitle, own unit pills, e.g. the one Verminlord Warbringer carrying Foulhide + Short-tempered; `split_pool._apply_unit_aliases`; in the split modes, an alias card left identical to its base unit's card once abilities moved to the turn cards is dropped, `_drop_identical_alias_cards` — the alias then only names the turn-card pills; an ability carried by both the alias and its base unit keeps only the base unit pill, `_collapse_alias_pills`) and `remove_abilities` (the abilities they summarize, removed everywhere except from the synthesis abilities themselves, which may reuse a removed name — warscrolls, enhancements, faction rules; list both the EN Wahapedia and FR names, since FR patches rename them). `all_lists` also carries two layout flags: `base_rules_last` (`render_rule_card(..., base_last=True)`: « Règles de base » becomes the last sub-section of each phase band, except the `deploy`/`round_start` bands, which follow game sequence — `render/layout._SEQUENCE_PHASES`). Warscroll cards always come right after the cover (every mode); in the split modes they are *also* repeated at the head of the « Tour de l'adversaire » section (padded to a recto), so each half of the printed booklet has its unit cards. Per-list `section_order` (phase key, e.g. `hero` -> unit sub-section titles opening that band, in order, `split_pool._apply_section_order`). Per-list `condition_overrides` (ability name -> Wahapedia `condition`, e.g. « Faim Dévorante » `Any Charge Phase` -> `Your Charge Phase`) moves an ability off a turn card where it can't be used (`"Passive (Enemy turn)"` keeps the PASSIF pill and puts a passive on « Tour adverse » only). A spell/summon whose « Annonce » `compress_spell_declare` actually changed gets the SIMPLE badge automatically. Every « Cible(s) : … » / « Target(s): … » sentence is followed by a line break when the text goes on on the same line (`roster_simplifications._break_after_target`, applied by `rewrite`/`rewrite_unit`, user rule). « Placer »/« set up » (a core-rules term) is always bold in ability text in every French mode and both `*-split-simple` modes (`render/text._bold_set_up`, enabled by `RenderOptions.bold_set_up`, applied at render; skips text already bold and « déplacer »/« remplacer »). Every mode: an ability title word wider than the name column breaks after a hyphen (`render/text._break_long_name`, « Porte-/Étendard »), never mid-syllable. Both `*-split-simple` modes also write a second PDF next to the first, `<liste> (…-split-simple-scenar).pdf` (`scenario_variant_path`, `RosterPdfResult.scenario_output_path`): same content plus the 12 battleplan cards of the General's Handbook 2026-27 at the end (`data/Manuel du général/MdG26-27 Scenarii.pdf`, scans, no text layer — one card per A4 page, enlarged and centred, scan margins cropped and clipped, the card's frame stored as the page `TrimBox`), 4 per A4 page (`assembly._append_scenario_pages`, sized and placed on each page's `TrimBox`, so the A4 side bands don't shrink the cards). In `*-split-simple` modes the CLI also prints two « À vérifier » lists (`resolution/absent_references.py`, read-only on the English Wahapedia text, never rewrites anything): abilities citing a faction warscroll absent from the list (`find_absent_references`) and abilities whose *friendly*-unit sentence cites a unit-type keyword (`UNIT_TYPE_KEYWORDS`) no unit of the list carries (`find_absent_keywords`) — candidates for principle 7, proposed to the player. Default output (every mode): `scratch/output/roster/<équipe>/<liste>/<liste> (<mode>).pdf` (`pdf_builder.default_output_path`; `<équipe>` = the list's subfolder under `data/Proposition de listes/`, `hybrid` → `defaut`).

- **Non-split modes** (`hybrid`/`en`/`fr`/`fr-extended`) reuse the split modes' layout ergonomics without their turn split: warscroll cards right after the cover, and the single merged « Aptitudes » card is rendered `sectioned=True` (horizontal phase header + gap between phase bands, Règles de base/Règles d'armée/Sorts/... sub-sections, « (suite) » on page break), ordered by `SPLIT_PHASE_ORDER` (green « any phase » band right after Déploiement), keeping the « Ma phase »/« Phase ennemi » pills, on pages with the split turn pages' top margin (`_PAGE_LABEL_MARGIN`, 14mm, no label).
- **`en-split-simple`**: `fr-split-simple`'s layout (`ModeSpec.split`/`ModeSpec.simple` in `modes.py`), in English. No `faction_rules_fr.json` patch (`ModeSpec.french` false): faction/unit text is plain Wahapedia. Generic abilities = `generic_core_abilities.json` overlaid by `data/json/generic_core_abilities_en.json` (`load_generic_core_abilities(..., en_path=...)`; each row names the French entry it replaces via `fr_name`, verbatim from the GW Core Rules PDF + Oct 2026 rules updates, `data/Battle tome/Download GW/eng_*`, source pill « CORE RULES »). Entries the 2026-27 General's Handbook changed (All-out Attack/Defence, Magical Intervention, Banish, Sacred Rites, Place of Power, Terrain, set-up sequence), season rules and tactic cards have no free English source and **stay French** until the user supplies an English scan. House labels (phase bands, pills, sub-sections, cover, legend) go through `render/text.tr()` (`_EN_LABELS`, enabled by `RenderOptions.english_labels`), while internal tags stay French (`« MdG »`, `SECTION_BASE`…), since sorting/matching logic keys on them. Per-list simplifications come from the `en` section of `roster_simplifications.json` (`load_roster_simplifications(..., lang="en")`, same shape; the French per-list simplifications are mirrored there, rewritten in English against Wahapedia's English names — except rules this mode still shows in French). French-text-only simplifications (`compress_spell_declare`, `compress_prayer_declare`, `compress_tactic_conditions`) don't apply.
- **Every mode**: a unit card's points read « base+N pts » when the list gives it paid options (` • X - (N) Points`, summed — `split_pool._PAID_OPTION_RE`); an origin badge that translates a Wahapedia keyword already on the ability (« Bannière Ensorcelée » / « Ensorcelled Banner », `_ENHANCEMENT_CATEGORY_LABELS`) replaces it instead of showing both (`render/cards.tag_ability_origin`); `remove_abilities` also filters generic/season rules.
- **FR/EN naming policy** (`ModeSpec.french_names`: French modes + `hybrid`): warscroll cards keep the English unit name with the French `subtitle_fr` under it, French weapon names (`faction_rules_fr.json` display keys, `_apply_display_fr`) and French weapon-ability tags (`RenderOptions.french_weapon_tags`, separate from `RenderOptions.french_keywords`, which stays French-modes-only). In `hybrid` only these display keys apply — ability text stays Wahapedia English.
- **Every mode**: page numbers « n / total » stamped bottom-centre after assembly (`assembly._stamp_page_numbers`, blank duplex pages stay blank); the cover legend explains the `_CastBadge` pictos *and* every pill family actually built for this PDF (`render/pills.pill_legend`, tracked by colour in `_pill`, reset by `reset_drawn_pills` at the start of `build_roster_pdf`), kept in one piece (`KeepTogether`) — under a long list it moves to the cover's back page. FR modes translate the standard weapon-ability tags (`render/text.weapon_abilities_fr`: Tir en Mêlée, Crit (Mortel), Anti-X (+1 Perf.)…); stat headers and card footers stay English (user choice).
